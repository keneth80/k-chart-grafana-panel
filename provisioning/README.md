The provisioned `Provisioned KChart Panel dashboard` contains working examples
for every chart type currently exposed by the plugin:

- Line with SVG
- Area with SVG
- Column with SVG
- Scatter with WebGL
- Candlestick with Canvas
- The empty-data state used by the browser test suite

All rendered examples share the same deterministic OHLC raw frame so their
geometry and renderer behavior can be compared without changing the query.

For more information, see [Provision dashboards and data sources](https://grafana.com/tutorials/provision-dashboards-and-data-sources/).
